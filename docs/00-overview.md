# 00 · 项目总览（Overview）

## 一句话愿景
做一款**网页可玩的像素风西游动作过关游戏**，玩家操控一只齐天大圣式的猿猴英雄，
用如意金箍棒战斗，并通过 **Solana 链** 拥有真正归属自己的角色 NFT、赚取代币、
登上链上排行榜，乃至与他人下注对战。

## 电梯演讲
《黑神话：悟空》让世界看到了西游题材的魅力，但它是重度 3A 主机/PC 游戏。
**Monkey Saga** 把这份"猴王打斗"的爽快感浓缩进**人人能在浏览器里秒开就玩**的
像素动作游戏，并用 Web3 让玩家真正"拥有"自己的猴王——皮肤、武器是 NFT，
战绩上链，技术好就能赚币。轻量、可病毒传播、原生加密。

## 设计支柱（Design Pillars）
1. **打击感优先**：金箍棒手感、闪避、定身法、Boss 战必须先在**离线**就好玩。
2. **链是增益不是门槛**：不连钱包也能玩；连了钱包解锁拥有权/赚取/竞争。
3. **原创但有魂**：原创美术与命名，但保留西游/猴王题材的精神内核。
4. **先 devnet、先安全**：涉及价值的一切先在测试网，反作弊与审计前置。

## 目标受众
- 喜欢西游/猴王题材的华语及全球玩家
- 像素动作/类银河恶魔城/横版闯关爱好者
- Solana 生态的 Web3 游戏玩家与 meme 社区

## 范围护栏（Scope Guardrails）
- **MVP 是一关**：一个完整关卡 + 一个 Boss，而非开放世界。
- **2D 不是 3D**：原作的 3D 系统取**简化子集**（见 GDD）。
- **不碰 IP 红线**：详见 `05-art-style-spec.md` 与 `07-security-anticheat.md`。
- **PVP 下注是延伸目标**：涉及真实金钱，需法律审查 + 合约审计后才上主网。
