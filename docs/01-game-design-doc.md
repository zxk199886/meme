# 01 · 游戏设计文档（GDD）

## 1. 核心循环（Core Loop）
进入关卡 → 用金箍棒打小怪、闪避、攒专注/灵蕴 → 抵达神龛检查点 →
击败 Boss（两阶段）→ 结算分数/灵蕴 →（连钱包时）上分 + 领取代币奖励 →
用代币铸造/升级 NFT 角色装备 → 带着新装备重玩更高难度。

## 2. 操作（默认键位，支持后续触屏映射）
| 操作 | 键 | 说明 |
|---|---|---|
| 移动 | ← → / A D | 左右移动 |
| 跳跃 | 空格 / W | 支持土狼时间(coyote)、跳跃缓冲(jump buffer) |
| 轻击 | J | 快、连招起手；金箍棒近战 |
| 重击 | K | 慢、伤害高、可破防/击退 |
| 闪避翻滚 | Shift / L | 消耗气力；**完美闪避**触发短暂慢动作 + 反击窗口 |
| 定身法 | U | 消耗法力，短暂冻住范围内敌人 |
| 交互/存档 | E | 在神龛处存档/回血 |

## 3. 玩家角色：猴王（原创"大圣"形象）
- **生命值（HP）**：受击减少，神龛处回满。
- **气力值（Stamina）**：冲刺/闪避/重击消耗，停手回复。对应原作"气力"。
- **专注点（Focus）**：命中累积，满段可释放蓄力重击（对应原作"专注/棍势蓄力"）。
- **法力（Mana）**：释放神通（定身法等）消耗，随时间/命中回复。

### 棍法（攻击系统，原作"三种棍势"的横版化）
- **MVP**：1 种基础棍法 = 劈棍（三连段轻击 + 蓄力重击）。
- **后续解锁**：
  - 立棍：撑棍跃起，范围下砸/破地板机关。
  - 戳棍：金箍棒拉长突刺，远距离戳击/穿刺。
- 轻/重击差异：轻击 DPS 高、硬直低；重击伤害高、能破盾/击退、有前后摇。

### 神通 / 法术（原作"奇术/身法/毫毛"的子集）
| 法术 | 阶段 | 效果 |
|---|---|---|
| **定身法** | MVP | 短暂冻结范围内敌人，免费输出窗口 |
| 身外身法（分身） | Phase 2+ | 召唤 1 个分身协同攻击数秒 |
| 铜头铁臂 | Phase 2+ | 短暂霸体/减伤，弹反近战 |

### 变身（72 变，后期内容，先入文档不入 MVP）
击败精英怪有概率掉落"变身"，限时变成该怪形态，使用其招数并**回满血**。
对应原作"化身/变身"。MVP 不实现，列为成长目标。

### 成长（灵蕴 → 灵光点）
杀怪/探索得 **灵蕴**（经验）。攒满一档得 **1 灵光点**（技能点），
可点入两棵小技能树：
- **棍法树**：解锁立棍/戳棍、增加连段、提升蓄力伤害。
- **神通树**：解锁新法术、降低法力消耗、延长定身时长。

## 4. 敌人与 Boss
### 小怪（MVP 做 1–2 种）
- **山贼狼妖（Grunt）**：地面巡逻 → 视野内追击 → 接触/挥砍伤害。简单状态机。
- **（可选）弓箭妖**：远程，定点放箭，逼迫玩家走位/闪避。

### Boss（MVP 做 1 个，两阶段）
- **首领·"白衣判官"（原创）**：
  - 一阶段：近战横扫 + 跳劈，留有可闪避破绽。
  - 血量过半进二阶段：新增召唤小怪 + 范围 AOE，节奏加快（对应原作"多阶段、随血量加招"）。
- 设计原则：**可观察、可学习、可适应**——每个攻击有可读的前摇与应对（闪避/定身/弹反）。

## 5. 关卡（MVP 一关）
- 用 **Tiled** 编辑的横版关卡：平台、尖刺/陷阱、可破坏机关、纵向探索空间。
- **神龛检查点**：原创存档点（对应原作"土地庙/神龛"），存档 + 回血 + 刷新小怪。
- 相机跟随玩家，含适度前瞻；关底为 Boss 房。
- 胜利条件：击败 Boss / 抵达终点；失败条件：HP 归零 → GameOver → 回最近神龛。

## 6. HUD / UI
- 左上：HP 条、气力条、法力条、专注段。
- 顶部中：当前棍法/已装备法术图标。
- 右上：分数 / 本局灵蕴。
- 连钱包后：右上角钱包按钮 + "通关可领取 X 代币"提示（由 React 外壳渲染，见架构）。

## 7. 反馈与手感细节（打击感清单）
- 命中顿帧（hit-stop）、屏幕轻微震动、受击闪白、击退。
- 金箍棒挥击的拖尾特效、定身法的冻结结晶特效。
- 音效：挥棍、命中、闪避"嗖"、定身"叮"、Boss 吼叫、神龛存档音。

## 8. 确定性要求（为反作弊重放铺路）
游戏核心逻辑采用**固定时间步长 + 种子化随机数**，使同样的输入序列产生同样的
结果，便于服务端无头重放校验分数（详见 `07-security-anticheat.md`）。
