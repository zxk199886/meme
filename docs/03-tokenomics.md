# 03 · 代币经济（Tokenomics）

> 本文为**初稿框架**，具体数值需结合社区规模、监管意见在主网前最终敲定。
> 所有参数先在 devnet 验证。涉及真实价值的设定需法律审查（见 `07`）。

## 1. 奖励代币（SPL Token）
| 项 | 取值（草案） | 说明 |
|---|---|---|
| 工作名 / ticker | "灵蕴币" / **$LING**（待定） | 原创命名 |
| 标准 | SPL Token（经典） | 兼容性最好；如需转账费再评估 Token-2022 |
| decimals | 9 | Solana 常规 |
| 总供应 | 上限封顶（如 1,000,000,000） | 防无限增发，治理可调 |
| mint authority | **后端独占**，最终交由多签/治理或销毁 | 反作弊核心（见 `07`） |

## 2. 产出（Faucet / Emission）
代币**不卖给玩家换 SOL 作为主要入口**，而是**玩出来的**（P2E）：
| 来源 | 产出 | 约束 |
|---|---|---|
| 击败小怪 | 每只少量 | 计入分数校验上限 |
| 通关 / 击败 Boss | 一次性较大额 | 每会话（nonce）只发一次，幂等 |
| 每日首通奖励 | 加成 | 每钱包每日上限 |

**硬约束**：
- 每钱包 / 每时间窗 产出上限（在程序/treasury 层兜底，即使校验器有 bug 也无法瞬间掏空）。
- 所有产出经服务端校验通过后才发放（见 `07`）。

## 3. 消耗（Sinks，维持经济平衡）
| 用途 | 消耗 | 去向 |
|---|---|---|
| 铸造 NFT 角色/装备皮肤 | 花 $LING（或 SOL） | 部分销毁 + 部分进 treasury |
| 升级/重铸装备 | 花 $LING | 销毁为主 |
| PVP 下注抽水（Phase 5） | 池子的 rake | treasury |
| 复活/续命等便利项（可选） | 少量 $LING | 销毁 |

> 健康的经济需要 **产出 ≈ 消耗**。若只产不耗，代币会无限通胀贬值。
> 设计目标：让"铸造/升级 NFT"成为主消耗，形成"打怪赚币 → 花币变强 → 打更难的怪"循环。

## 4. 分配（若未来有固定供应分配，草案）
| 份额 | 比例（草案） | 锁仓 |
|---|---|---|
| 玩家产出池（P2E emission） | 50% | 按里程碑线性释放 |
| 生态/社区激励 | 20% | 分期 |
| 团队 | 15% | 长锁仓 + 线性归属 |
| 流动性 / treasury | 15% | — |

## 5. NFT（Metaplex Core）
- **角色皮肤**：不同猴王造型（不侵权的原创设计）。
- **武器变体**：金箍棒外观/特效变体（数值影响需谨慎，避免 pay-to-win 失衡）。
- 稀有度分层；铸造消耗 $LING 形成 sink。
- 选择 Core 而非 Token Metadata 的理由见 `adr/0003`。

## 6. 风险与红线
- **不做承诺收益/投资属性宣传**——避免被认定为证券。
- P2E 代币有真实价值 + PVP 下注 → 可能触发**赌博/资金转移/证券**监管。
  主网/赋真实价值前**必须法律审查**，考虑地域限制与"无需购买即可参与"框架。
- 详见 `07-security-anticheat.md`。
