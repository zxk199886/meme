# 05 · 美术与音频规范（Art & Audio Spec）

## 0. IP 合规（最重要）
- **禁止**使用《黑神话：悟空 / Black Myth: Wukong》的名称、Logo、角色设计、UI、
  任何截图或 ripped 资产。
- 《西游记》原著属**公有领域**——猴王、金箍棒、紧箍咒、师徒取经等**题材/母题**可借鉴；
  但任何现代游戏对其的**具体表达**（特定角色造型、关卡设计、原画）不可照搬。
- 所有美术必须**原创**或采用**明确可商用授权**（CC0/自有）的素材。
- **资产授权台账**：每个 sprite/tileset/音频登记作者与许可证，存于 `assets-src/CREDITS.md`。
- 角色/游戏命名避开商标；用原创工作名（Monkey Saga / WuTale 等），最终名做商标检索后定。

## 1. 像素美术规范
| 项 | 规范（草案） |
|---|---|
| 基础瓦片尺寸 | 32×32 px |
| 角色精灵 | 玩家约 32×48 px；小怪 32×32–48×48；Boss 96×96+ |
| 渲染缩放 | 整数倍缩放（pixelArt: true，禁用抗锯齿），保持像素锐利 |
| 调色板 | 受限调色板（如 32–48 色），统一国风色调：朱红/墨黑/金/青绿/土黄 |
| 分辨率/视口 | 逻辑分辨率如 480×270（16:9），整数放大到窗口 |

## 2. 动画（Aseprite → atlas）
| 角色 | 需要的动画 |
|---|---|
| 玩家猴王 | idle / run / jump / fall / 轻击 1-2-3 / 重击 / 闪避翻滚 / 定身施法 / 受击 / 死亡 |
| 小怪（狼妖） | idle/patrol / chase / attack / hit / death |
| Boss（白衣判官） | idle / 横扫 / 跳劈 / 召唤 / AOE / 阶段转换 / hit / death |
| 特效 | 金箍棒挥击拖尾 / 命中火花 / 定身冻结结晶 / 神龛存档光 |

约定：导出为 spritesheet + JSON atlas（Phaser Aseprite 加载），帧率与 hit-stop 在 `constants.ts` 调。

## 3. 场景 / Tileset（国风像素）
- 取材原创化的西游意象：花果山、古道、佛塔/古刹剪影、石桥、灯笼、藤蔓。
- **神龛检查点**：原创小庙/神龛 sprite（非照搬原作土地庙造型），带存档光效。
- Tiled 编辑：分图层（背景视差 / 平台碰撞层 / 装饰 / 机关 / 出生点&触发器对象层）。

## 4. UI 美术
- HUD：HP/气力/法力/专注 条，国风边框；棍法与法术图标。
- 字体：像素字体（含中文像素字体或位图字处理 CJK）。
- 钱包/排行榜/铸造面板由 React 渲染，风格与游戏 HUD 统一（朱红+金描边）。

## 5. 音频
- **全部原创或可商用授权**，登记许可证。
- BGM：国风/古风 + chiptune 混合；菜单、关卡、Boss 战分轨。
- SFX：挥棍、命中、闪避"嗖"、定身"叮——冻结"、跳跃、受击、Boss 吼、神龛存档、UI 点击。
- 音频管线：`AudioManager` 统一管理音量/静音/复用。

## 6. 资产交付清单（Phase 2 最小集）
- 玩家全套动画、1 种小怪、1 个 Boss、1 套关卡 tileset、神龛、基础特效、
  1 段关卡 BGM + 1 段 Boss BGM + 核心 SFX 包、像素字体、UI 元件。
